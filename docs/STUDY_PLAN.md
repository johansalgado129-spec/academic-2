# Plan intensivo de preparación

## Semana 1 — C# sólido
- Sintaxis, tipos y nullability
- Métodos, clases, interfaces y herencia
- Colecciones y genéricos
- LINQ
- Excepciones
- Delegados, eventos y lambdas

## Semana 2 — Datos y backend
- Diseño relacional
- SQL: joins, subconsultas, CTE, índices y transacciones
- EF Core
- ASP.NET Core Web API
- Inyección de dependencias
- HTTP y REST

## Semana 3 — Nivel de vacante
- async/await
- Seguridad
- Testing con xUnit
- SOLID y patrones
- Clean Architecture
- Debugging y rendimiento
- Simulacros técnicos

## Rutina diaria sugerida

- 45 min: teoría
- 60 min: escribir código sin copiar
- 45 min: ejercicios SQL
- 30 min: preguntas de entrevista
- 30 min: proyecto final

Regla: si no puedes explicar una solución sin mirar el código, todavía no la dominas.
